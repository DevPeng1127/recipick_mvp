# Recipick 개발 이력

정리일: 2026-10-30 (한국 시간). 개발 회고·진행 보고서·릴리스 노트를 만들 때 시작점으로 사용하는 요약이다. 현재 브랜치에 포함된 Git 기록과 기존 개발 문서를 근거로 작성했다. 초기 기록은 커밋 메시지 기준이며, 이번에 과거 기능을 다시 검증한 것은 아니다. 기능 구현·검증일과 커밋일이 다른 경우 별도로 적는다. 로컬 커밋 완료가 운영 배포 완료를 뜻하지 않는다.

## 문서별 역할

- 이 문서: 날짜순 주요 변경, 결정 이유, 검증 요약, 커밋을 연결하는 색인.
- [기능 개발 기록](feature-roadmap.md): 기능별 합의 사항, 구현 범위, 테스트 근거, 남은 제한.
- [코드 점검·인계 기록](code-audit-and-repair-log.md): 점검 01~11과 최신 작업 상태, 실패·재검증 및 데이터 보존 기록.
- [README](../README.md): 현재 기능 사용법과 개발 환경 실행 방법.
- [보관 기한 추천 기준](expiry-guidance.md): 추천 일수의 근거와 적용 조건.

앞으로 완료한 작업은 한 항목씩 여기에 추가한다. **날짜 / 문제·목표 / 확정한 정책 / 완료 범위 / 검증 / 한계 / 커밋 또는 고유 이력 ID**를 남기고, 제안·보류·구현 완료·사용자 확인·커밋·배포 상태를 구분한다. 테스트 수는 해당 시점의 결과이며 서로 더해 누적 실행 수로 표시하지 않는다. 비밀키·실제 사용자 데이터는 기록하지 않는다.

### 최신 항목의 판단과 한계

- 문제: 냉동 피자를 도우로 취급하고 주스와 억지로 섞는 추천이 관찰됐다. 목표를 “새 레시피 만들기”에서 **보유 음식으로 현실적인 메뉴 구성하기**로 조정했다.
- 확정 정책: 선택한 재료를 우선 활용하되 별도 메뉴·곁들임으로 나누거나 제외 이유를 설명한다. 알레르기·제외 설정을 우선한다. 날짜 출처를 구분하고 날짜가 지난 항목은 우선 선택·자동 차감 배정에서 제외한다.
- 검증: 가상 피자+주스의 자연스러운 분리, 원재료 볶음밥, 음료 단독 안내를 실제 응답으로 확인했다. 피자 0.5개와 주스 0.25L 차감 및 새로고침 후 중복 방지를 격리 DB에서 확인했다.
- 제한: AI의 양념 누락·이름·수량 오류를 모두 의미적으로 검사하지 않는다. 사용자가 메뉴와 차감 목록을 확인해야 한다. 모바일은 390px iframe 검사이며 출처 불명 MutationObserver 오류 1건을 상세 기록에 남겼다. 모바일 실기기·OAuth 재검증은 아니다.
- 상태: 2026-10-30 사용자가 **“응 여기까지 일단 커밋하자. 문서화도 잊지 않을 거지? 개발 히스토리도 나중에 뽑아볼 수 있도록 정리되면 좋겠어.”**라고 결과와 커밋을 승인했다. 코드·테스트·문서를 같은 로컬 커밋으로 기록한다. 다음 항목은 시작하지 않는다.
- 커밋 제목: `feat: recommend practical menus with priority ingredients`. 같은 커밋 안에 자신의 해시를 기록할 수 없으므로 고유 ID `MENU-20261030`을 커밋 본문에 남긴다. 아래 명령으로 해시를 확인한다.

## Git 이력 조회·내보내기

저장소 루트에서 실행한다. 조회 대상은 **현재 브랜치 HEAD에 포함된 커밋**이며 다른 브랜치의 미병합 작업·미커밋 파일은 포함하지 않는다. 과거 커밋 메시지의 기술 스택은 당시 기록이며 현재 스택은 README를 따른다.

```powershell
# 최신 기능의 고유 ID로 커밋 조회
git log -1 --format="%h %s" --fixed-strings --grep="History-ID: MENU-20261030" HEAD

# 현재 브랜치에 포함된 변경을 오래된 순서로 조회
git log --reverse --date=iso-strict --format="%h %ad %s" HEAD

# Excel 등에서 사용할 CSV: 현재 사용자의 임시 폴더에 저장
git log --reverse --format="%H%x09%aI%x09%s" HEAD |
    ConvertFrom-Csv -Delimiter "`t" -Header commit, authored_at, title |
    Export-Csv -LiteralPath "$env:TEMP\recipick-git-history.csv" -NoTypeInformation -Encoding utf8
```

CSV는 커밋 원장이고 이 문서는 제품 변화의 요약이다. 보고서를 만들 때 두 자료와 상세 검증 문서를 함께 사용한다. 원격 푸시·운영 배포는 별도 승인과 확인이 필요한 상태이며, 배포 전 운영 전용 JWT 키 준비 확인 원칙을 유지한다.
