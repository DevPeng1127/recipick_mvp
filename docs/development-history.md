# Recipick 개발 이력

정리일: 2026-11-02 (한국 시간). 개발 회고·진행 보고서·릴리스 노트를 만들 때 시작점으로 사용하는 요약이다. 현재 브랜치에 포함된 Git 기록과 기존 개발 문서를 근거로 작성했다. 초기 기록은 커밋 메시지 기준이며, 이번에 과거 기능을 다시 검증한 것은 아니다. 기능 구현·검증일과 커밋일이 다른 경우 별도로 적는다. 로컬 커밋 완료가 운영 배포 완료를 뜻하지 않는다.

### 최신 항목의 판단과 한계

- 문제: 냉동 피자를 도우로 취급하고 주스와 억지로 섞는 추천이 관찰됐다. 목표를 “새 레시피 만들기”에서 **보유 음식으로 현실적인 메뉴 구성하기**로 조정했다.
- 확정 정책: 선택한 재료를 우선 활용하되 별도 메뉴·곁들임으로 나누거나 제외 이유를 설명한다. 알레르기·제외 설정을 우선한다. 날짜 출처를 구분하고 날짜가 지난 항목은 우선 선택·자동 차감 배정에서 제외한다.

## Git 이력 조회·내보내기

저장소 루트에서 실행한다. 조회 대상은 **현재 브랜치 HEAD에 포함된 커밋**이며 다른 브랜치의 미병합 작업·미커밋 파일은 포함하지 않는다. 과거 커밋 메시지의 기술 스택은 당시 기록이며 현재 스택은 README를 따른다.

```powershell
# 최신 기능의 고유 ID로 커밋 조회
git log -1 --format="%h %s" --fixed-strings --grep="History-ID: MENU-20261030" HEAD

# 현재 브랜치에 포함된 변경을 오래된 순서로 조회
git log --reverse --date=iso-strict --format="%h %ad %s" HEAD

# Excel 등에서 사용할 CSV: 현재 사용자의 임시 폴더에 저장
git log --reverse --format="%H%x09%aI%x09%s" HEAD |
    ConvertFrom-Csv -Delimiter "`t" -Header commit, authored_at, title |
    Export-Csv -LiteralPath "$env:TEMP\recipick-git-history.csv" -NoTypeInformation -Encoding utf8
```

CSV는 커밋 원장이고 이 문서는 제품 변화의 요약이다. 보고서를 만들 때 두 자료와 상세 검증 문서를 함께 사용한다. 현재 브랜치 원격 푸시는 사용자 승인 후 완료했고, 기본 브랜치 병합·운영 배포는 별도 요청 대상이다. 배포 전 운영 전용 JWT 키 준비 확인 원칙을 유지한다.
